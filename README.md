# SeSAC Salesforce101 프로젝트

Salesforce S.T.A.Track 3기 Salesforce101 과정에서 만든 Salesforce DX 프로젝트입니다. Developer Edition org에 배포해서 사용합니다.

## Day3 미니 프로젝트: 입출금 대조 관리 앱

은행 운영팀이 매일 **시스템 장부 잔액과 실제 통장 잔액**을 맞추고, 안 맞는 금액을 끝까지 추적·보고하는 앱입니다. 외국계 은행 운영팀에서 거래 대사와 환율 확인을 했던 경력을 바탕으로 설계했습니다. 회사·인물·금액은 모두 가상입니다.

- 차이 0원 + 남은 항목 0건이면 **자동 완료**, 아니면 보고 내용과 보고 대상 팀장을 **자동 작성**
- 대조 입력 마법사(스크린 Flow), 홈 현황 카드(LWC + Apex), 리포트 차트
- **운영팀만 접근** (권한 세트 + 비공개 공유), 완료 후 잠금과 변경 이력
- Apex 테스트 13개

자세한 설명: [README-bank-recon.md](README-bank-recon.md) · 발표 자료: [docs/presentation](docs/presentation)
